웹 브라우저(`HTML`)는 브라우저 창을 닫거나 컴퓨터를 끄면 OS가 프로세스를 중단시키므로, **24시간 무중단 실행 + 영구 자가학습**을 위해서는 코드를 **내 PC가 아닌 클라우드 서버**에 올려야 합니다.
아래 **GitHub 무료 클라우드 방식**을 사용하면 **서버 비용 0원**으로 15분마다 24시간 내내 AI가 실시간 시세를 조회해 1,000만 원을 모의투자하고, 학습 결과를 자동 저장하며, 스마트폰/PC 어디서든 웹 주소로 수익률과 매수·매도 사유를 확인할 수 있습니다.

## 🚀 3분 만에 끝내는 무료 24시간 클라우드 배포 순서

### 1단계: GitHub 무료 계정 생성 및 새 저장소(Repository) 만들기
1. [GitHub](https://github.com)에 로그인 후 우측 상단 **`+` → `New repository`** 클릭
2. 저장소 이름(예: `ai-quant-247`) 입력 후 **`Create repository`** 클릭

### 2단계: 압축 해제한 파일 전체 업로드
1. 이 패키지의 압축을 푼 폴더 안에 있는 아래 파일들을 저장소에 업로드합니다:
   - `cloud_worker.py` (24시간 실시간 주가 조회 & 300원칙 자가학습 엔진)
   - `principles_300.json` (300가지 투자 원칙 데이터베이스)
   - `index.html` (어디서나 접속 가능한 실시간 수익률·매매사유 대시보드)
   - `.github/workflows/ai_247_trader.yml` (15분마다 자동 실행 스케줄러)

### 3단계: 자동 실행 권한 활성화 (클라우드 무인 가동 시작)
1. 저장소 상단 **`Settings` → 좌측 `Actions` → `General`** 이동
2. 맨 아래 **Workflow permissions**에서 **`Read and write permissions`** 선택 후 **`Save`** 클릭
3. 상단 **`Actions`** 탭으로 이동 → **`24/7 Cloud AI Paper Trader & Self-Learner`** 클릭 → **`Run workflow`** 한 번 누르면 즉시 첫 매매가 시작되며, 이후 **컴퓨터를 꺼도 24시간 15분 간격으로 자동 실행**됩니다.

### 4단계: 스마트폰·PC에서 언제든 수익률 확인하기 (GitHub Pages)
1. 저장소 상단 **`Settings` → 좌측 `Pages`** 이동
2. **Branch**를 `main` / `/ (root)`로 선택 후 **`Save`** 클릭
3. 1분 뒤 발급되는 `https://[내아이디].github.io/ai-quant-247/` 주소로 접속하면 **창을 닫아두었던 동안 AI가 체결한 모든 매수·매도 내역, 상세 사유, 자가학습 진화 단계, 수익률 그래프**를 실시간으로 볼 수 있습니다.
