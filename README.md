# AI 펀드 1000 — 실시간 모의투자

가상의 1,000만 원을 **실제 시장의 실시간 시세**로 굴리는 모의투자 프로그램입니다.
1분마다 시세를 받아 「나의 투자 원칙 300」을 옮긴 규칙으로 판단하고, 그 순간 가격에 바로 모의 체결합니다.
실제 돈과 실제 주문은 전혀 움직이지 않습니다.

## 실행 방법

1. 파이썬 3.10 이상을 설치합니다. (python.org → 설치할 때 "Add Python to PATH" 체크)
2. 이 폴더에서 실행 파일을 더블클릭합니다.
   - 윈도우: `실행(윈도우).bat`
   - 맥: `실행(맥).command` (처음 한 번은 우클릭 → 열기)
3. 브라우저에 대시보드(`http://127.0.0.1:8800`)가 자동으로 열립니다.
4. 창을 켜 둔 동안 계속 거래합니다. 컴퓨터가 잠자기에 들어가거나 창을 닫으면 멈추고, 다시 켜면 이어서 운용합니다.

장이 닫힌 시간에 화면과 규칙을 먼저 보고 싶으면 `데모로 시험(윈도우).bat`(또는 `python app.py --demo`)을 실행하세요.
데모는 가짜 시세를 쓰고, 기록도 `data/portfolio_demo.json`에 따로 저장돼 실제 기록과 섞이지 않습니다.

## 컴퓨터가 꺼져 있어도 돌리기 (GitHub, 무료)

GitHub 서버가 장중 약 10분마다 프로그램을 대신 실행하고, 대시보드를 인터넷 주소로 올려 줍니다. 카드 등록이 필요 없습니다.

1. **github.com에 가입**합니다.
2. 오른쪽 위 **+ → New repository**. 이름은 `ai-fund`, **Public** 선택, **Create repository**.
   (Private로 만들면 무료 실행 시간이 한 달 2,000분이라 중간에 멈춥니다.)
3. 새 저장소 화면의 **uploading an existing file**을 누르고, 이 폴더 안의 파일과 폴더를 **전부** 끌어다 놓은 뒤 **Commit changes**.
4. 자동 실행 설정 파일 넣기: **Add file → Create new file**, 파일 이름 칸에 `.github/workflows/trade.yml`을 그대로 입력하고,
   이 폴더의 `자동실행설정_trade.yml` 내용을 전부 복사해 붙여넣은 뒤 **Commit changes**.
   (윈도우에서 3번에 `.github` 폴더까지 올라갔다면 이 단계는 건너뛰어도 됩니다.)
5. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿉니다.
6. **Settings → Actions → General → Workflow permissions**에서 **Read and write permissions**를 고르고 Save.
7. **Actions** 탭 → 왼쪽 **AI 펀드 실시간 모의투자** → **Run workflow**를 한 번 누릅니다.
8. 2~3분 뒤 `https://내아이디.github.io/ai-fund/` 에서 대시보드가 열립니다. 휴대폰 즐겨찾기에 넣어 두세요.

알아 둘 점
- 점검 간격은 약 10분입니다. GitHub가 바쁠 때는 예약 실행이 몇 분씩 늦거나 가끔 건너뛰어집니다. 1분 단위가 필요하면 컴퓨터에서 실행하는 방식을 쓰세요.
- 저장소가 Public이라 운용 기록과 투자 원칙을 다른 사람도 볼 수 있습니다(가상 투자 기록입니다).
- 대시보드에서 관찰 대상을 바꾸면 "저장 코드 복사 → selection.json 편집 열기 → 붙여넣기 → Commit" 순서로 저장합니다. 저장하면 바로 한 번 다시 실행됩니다.
- 피할 종목(`avoid`)이나 규칙 숫자는 저장소의 `config.json`을 GitHub 화면에서 연필 아이콘으로 고치면 됩니다.
- 컴퓨터 실행과 GitHub 실행을 동시에 하면 기록이 두 갈래로 나뉩니다. 한 곳만 쓰세요.

## 관찰 대상 고르기

대시보드의 **관심목록**에서 종목마다 체크 상자를 켜고 끌 수 있습니다.

- **체크한 종목만** AI가 새로 살 후보로 검토합니다. 끄면 그 종목은 사지 않습니다.
- 이미 가진 종목을 꺼도 원칙에 따라 계속 관리합니다(논리가 깨지면 매도 등).
- 그룹 이름 옆 **모두 켜기 / 모두 끄기**로 한꺼번에 바꿀 수 있습니다. 검색어나 필터가 걸려 있으면 보이는 종목에만 적용됩니다.
- **종목 직접 추가**: 미국은 티커 그대로(`AMD`), 코스피는 `005380.KS`, 코스닥은 `035420.KQ`처럼 입력합니다. 추가한 종목은 바로 켜지고, 이름을 눌러 삭제할 수 있습니다.
- 선택 내용은 `data/selection.json`에 저장돼 다음 실행 때도 유지됩니다.
- 유럽·홍콩·대만 종목과 지수는 "관찰만"으로 표시되며 매매 대상으로 켤 수 없습니다.

## 어떻게 판단하나

| 원칙 | 프로그램 규칙 |
|---|---|
| 3·15·39·238 주식 비중 높게, 현금은 기회용 | VIX 30 이상이면 현금 20~35%, 20~30이면 15~25%, 20 미만이면 10~20% |
| 22·32~37 기술주가 핵심 | 반도체·AI·소프트웨어·로보틱스·바이오·우주·핀테크 가산점, 기술주 70% 이상 유지 |
| 29·249·269 집중 위험 관리 | 대형주(시총 1,000억 달러 이상) 15%, 그 외 7%, 비트코인 5% 상한 |
| 101~130·157~180 재무·가치 평가 | 매출 성장, 영업이익률, 잉여현금흐름, 부채비율, PEG로 0~100점 |
| 226·227 분석 없이 사지 않음 | 재무 항목이 3개 이상 확인된 종목만 매수 |
| 230 분할 매수 | 목표 비중의 1/3씩, 한 종목은 하루 한 번만 |
| 231 추격 매수 금지 | 당일 +8% 넘게 오른 종목은 그날 사지 않음 |
| 233·234·258 하락만으로 사고팔지 않음 | 점수(펀더멘털)가 기준을 넘을 때만 매수, 주가가 빠져도 점수가 괜찮으면 보유 |
| 257·261 논리 훼손 시 매도 | 점수 42점 미만이면 전량 매도 |
| 248·263 영구 손실 방지 | 원가 -25%(비트코인 -30%)에서 점수가 58점 미만이면 매도 |
| 259·262 과열 시 일부 차익 | 애널리스트 목표가 상단을 넘으면 1/3만 매도 |
| 195·255 회계·규제 문제 | `config.json`의 `avoid` 목록 종목은 매수 금지, 보유 중이면 정리 |
| 288 불필요한 매매 줄이기 | 하루 6건, 거래 간격 10분 이상 |

숫자는 모두 `config.json`에서 바꿀 수 있습니다. 엔비디아처럼 피해야 할 종목은 `avoid`에 이유와 함께 넣으면 됩니다.

## 알아 둘 점

- **시세 출처:** 야후 파이낸스 무료 시세. 미국 주식은 거의 실시간이고, 한국 주식은 몇 분~20분 늦을 수 있습니다. 시세가 20분보다 오래되면 그 종목은 거래하지 않습니다.
- **거래 대상:** 미국·한국 주식과 비트코인. 유럽·홍콩·대만 종목은 관찰만 합니다.
- **판단 방식:** 숫자로 된 규칙에 따른 자동 판단입니다. 뉴스 내용을 읽고 해석하지는 않습니다. 뉴스로 생긴 악재는 `avoid`에 직접 넣어 주세요.
- **한국 종목 재무 데이터:** 야후에 없는 경우가 많아, 데이터가 부족한 한국 종목은 새로 사지 않을 수 있습니다.
- **기록:** `data/portfolio.json`에 저장됩니다. 처음부터 다시 하려면 이 파일을 지우지 말고 따로 백업한 뒤 원본 시작 파일로 바꾸세요.
- 모의투자 기록일 뿐 투자 권유가 아닙니다.
